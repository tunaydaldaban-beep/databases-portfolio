# Five integrity defects — SQL evidence

The deliberately broken fixture is preserved in [legacy_setup.sql](legacy_setup.sql). [Queries](integrity-audit.sql) and [actual results](integrity-results.txt) are regenerated by run_audit.py.

| Defect | Actual evidence | Production consequence | Proposed repair |
|---|---|---|---|
| Orphan machine reference | job 3 references cnc-05; no parent exists | Job cannot be reliably attributed to a machine/site | Resolve or quarantine the row, then enforce NOT NULL machine_id FK |
| Duplicate natural key | P-1003 has 2 copies | Joins and stock/cost totals can double-count | Confirm duplicate identity, reconcile and enforce part_no PK |
| Text price ordering | `< '15'` returns only P-1001 at 12.50; numeric comparison also returns both P-1003 rows at 9.90 | Price filters and reports silently omit qualifying parts | Validate Decimal values, numeric storage and DB price checks |
| Invalid installation date | RANDOM-NAME has installed = unknown | Date ordering, service-age calculations and schedules become unreliable | Obtain the real date or agree an explicit unknown-date policy; validate calendar dates |
| Comma-separated association | Naive equality join returns job 2 twice and job 3 once; job 1 disappears | Multi-part jobs disappear and duplicated parts inflate results | Replace parts_used with job_part and enforce both FKs plus composite PK |

CAST fixes the comparison for this known fixture but is not input validation: malformed strings may coerce to zero. A date-shaped string is not necessarily a valid calendar date. The duplicate join is caused by duplicate part rows as well as the list-design problem.

## Migration decisions still needed

No automatic migration is claimed. Do not invent cnc-05, silently delete an orphan, fabricate an installation date, or assume identical technician names identify the same person. Agree corrections with the data owner, preserve an audit trail, and load only reconciled records into the new contract. The fixture remains intentionally defective so the evidence can be reproduced.
